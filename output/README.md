# Model Prediction Outputs

This directory contains the final prediction outputs generated by the Model V2 inference pipeline for all 1,732,544 test entities from `student_resource/dataset/test/test_source1.tsv`.

## Files Overview

| File | Size | Records | Description | Git Status |
| :--- | :--- | :--- | :--- | :--- |
| `matching_results.tsv` | 80.11 MB | 1,732,545 lines (1 header + 1,732,544 rows) | Official leaderboard submission file. Contains matched entity IDs for each test source entity. | Tracked in Git (<100MB limit) |
| `candidate_pairs.tsv` | 421.00 MB | 1,732,545 lines (1 header + 1,732,544 rows) | Comprehensive audit file containing the candidate pairs evaluated by the ML model. | Excluded from Git (>100MB GitHub limit) |

## Output Schema Specifications

### 1. `matching_results.tsv` (Leaderboard File)
Tab-separated values file conforming to the official competition format:
```tsv
source1_entity_id	matched_entity_ids
S1-000000001	S2-987654321
S1-000000002	
S1-000000003	S3-123456789,S2-112233445
```
- Multiple matches for a single entity are separated by commas (`,`).
- Entities with no high-confidence match above the calibrated threshold (0.40) have an empty `matched_entity_ids` field.

### 2. `candidate_pairs.tsv` (Pre-Scoring Candidate Audit)
Tab-separated values file containing all candidates generated during the blocking stage prior to LightGBM scoring:
```tsv
source1_entity_id	candidate_entity_ids
S1-000000001	S2-987654321,S3-554433221
S1-000000002	S2-888777666
```

## Reproducing Excluded Files

To reproduce `candidate_pairs.tsv` (and `matching_results.tsv`) locally:
```bash
python3 code/business_entity_resolution/src/run_inference.py \
    --test-s1 student_resource/dataset/test/test_source1.tsv \
    --test-s2 student_resource/dataset/test/test_source2.tsv \
    --test-s3 student_resource/dataset/test/test_source3.tsv \
    --output-dir output
```
Alternatively, extract both files from the packaged submission archive `submission.zip`.
